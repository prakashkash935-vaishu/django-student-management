# Django Student Management System

A web application to manage students and courses, built with Django.

## Features
- Add, view, edit and delete students (CRUD)
- Course and student models with ForeignKey relationship
- Django admin panel

## Tech Stack
Python, Django, SQLite (MySQL planned), HTML, CSS

## How to Run
1. Clone the repo
2. Create and activate a virtual environment
3. pip install django djangorestframework
4. python manage.py migrate
5. python manage.py runserver
